

# shortest-path-finding-turtle-sim
This repository contains the code for the ROS2 node that performs dijkstra's algorithm on grid of points generated by a PRM simulator, and then uses pure pursuit to follow that shortest line path smoothely till the end target is reached. It avoids pre-determined randomly generated obstacles that are sprinkled using the turtlesim sketch mechanism.
